Included: index.html (10 calculators), guides.html, privacy.html, terms.html,
disclaimer.html, robots.txt and sitemap.xml.

FREE HOSTING + FREE SUBDOMAIN:
1. Extract this ZIP.
2. Upload all files/folders to a new GitHub repository (files must be at repository root).
3. Cloudflare Dashboard > Workers & Pages > Create > Pages > Connect to Git.
4. Select your GitHub repository.
5. Framework preset: None. Build command: leave blank. Build output directory: / (if not accepted, use .).
6. Deploy. Cloudflare assigns a free https://PROJECT-NAME.pages.dev address.
7. In Pages > your project > Custom domains, a custom domain can be connected if you already own it. A free pages.dev subdomain is provided; a free .com domain is not.

BEFORE PUBLIC LAUNCH:
- Replace YOUR-DOMAIN.example in canonical URL, JSON-LD, sitemap.xml and robots.txt after deciding your final address.
- Replace hello@YOUR-DOMAIN.example with a real contact email.
- Update Privacy/Terms/Disclaimer to reflect actual data collection, analytics, ads and applicable laws.
